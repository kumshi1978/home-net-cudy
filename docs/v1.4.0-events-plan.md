# HOME NET v1.4.0-dev — Event Monitor

## Цель версии

Добавить журнал событий для мониторинга состояния Cudy/OpenWrt без автоматического вмешательства в работу сети.

## Новые возможности

- журнал событий `events.log`;
- фиксация изменения состояния OK/FAIL;
- фиксация восстановления RECOVERY;
- контроль FakeIP;
- контроль sing-box;
- контроль Podkop;
- контроль AmneziaWG.

## Принцип работы

Текущий статус сохраняется.

При следующей проверке сравнивается:

`предыдущее состояние -> текущее состояние`

Примеры:

```
OK -> FAIL
FAIL -> OK
VPN MAIN -> VPN BACKUP
```

## Ограничения v1.4.0

Автоматические перезапуски сервисов пока не выполняются.

Сначала собирается статистика работы и реальные причины сбоев.
