# HOME NET 1.7.5: автоматическая настройка SSH-доступа

Общий установщик добавляет публичный служебный ED25519-ключ только на два
квартирных Cudy с независимо подтверждёнными ключами хоста. Остальные установки
HOME NET пропускают этот шаг. Имена устройств и IP-адреса не являются основанием
для предоставления доступа. Дачные устройства пока не включены.

На установленной 1.7.4/1.7.5 применяется только эта политика: компоненты не
скачиваются, службы и сетевые интерфейсы не перезапускаются. Автообновлятор
сохраняет свои проверки свежего здоровья и блокировки. При ручной установке
новая версия также записывается только после свежего успешного мониторинга.

Существующие ключи сохраняются. Повторная установка не создаёт дубликаты.
Новая запись запрещает forwarding и интерактивный терминал; обычные команды
SSH доступны root. Приватный ключ не входит в репозиторий.

Публикация выпуска не доказывает установку: итог проверяется новым SSH-входом
и чтением версии на каждом устройстве. Роутеры с выключенным автообновлением
или ручной политикой не обновятся автоматически. Для первого этапа используется
кольцо canary. До проверки основного квартирного Cudy кольцо stable не открывать.
