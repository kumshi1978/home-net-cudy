# HOME NET 1.7.12 — состояния интерфейсов Cudy

Go-агент передаёт фактическое состояние awg_main, awg_backup, awg_backup2, выбранный путь Podkop, свежесть отчётов, ошибки и версии применения плана. Обычный Failover сохраняет фиксированное назначение VDS. Совместимая панель — HOME NET Panel 0.1.0; поднятые интерфейсы в свежих отчётах выделяются жирным.

При явно подтверждённой замене неактивного профиля удаляются устаревшие peers и пользовательские DNS, отключается Default gateway, проверяются Endpoint port и Listen port. Для плана с одним резервом предусмотрено удаление неиспользуемого awg_backup2 под общей блокировкой и с журналом восстановления. Удаление активного интерфейса запрещено. Эти действия требуют отдельного сохранения назначений; обновление ПО само их не запускает.

На резервном Cudy успешно проверены установка кандидата, версия 1.7.12, целостность кода, службы, локальная проверка установки и несколько свежих отчётов в реальной панели. Новый процесс не сообщил ошибок poll. Сеть, Podkop, конфигурация Failover и ключ age совпали с исходными; активным остался awg_main. Служебный JSON агента пересохранён с меткой полученной версии плана; его полный байтовый хэш изменился, поэтому неизменность этого файла не заявляется. Секреты не выводились; авторизация и проверка подписанного плана подтверждены работающим обменом.
