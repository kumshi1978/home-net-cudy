# HOME NET 1.7.12 — draft for router validation

Prepare the interface synchronization update for ARM64 Cudy routers. This draft
does not change the stable v1.7.11 release or manual rollout policy and has not
been installed on hardware.

The native 1.7.12 agent reports all three fixed AWG interfaces, current Podkop
selection, freshness, collector errors and distinct received/prepared/applied plan
revisions through existing authenticated HTTPS polling. Canonical HMAC and age
remain unchanged, with no router Python dependency.

Explicit inactive-profile replacement leaves one current peer, disables default
routes and peer DNS, clears custom DNS, and checks endpoint and local listen ports.
An explicitly saved two-slot plan can remove inactive awg_backup2 under the shared
maintenance lock. Active-interface deletion and unfinished recovery are refused.

Compatible panel: HOME NET Panel 0.1.0. Plans saved before the panel upgrade must
be saved again before upgraded profile/order/cleanup actions are authorized.
Ordinary failover never changes fixed VDS assignments.
