# HOME NET 1.7.11 — install independently of VPN availability

Fixes a 1.7.10 installation stop when Monitoring reports VPN or external-country
probe failure. A fresh completed Monitoring cycle and healthy local Podkop/
sing-box services remain required, along with installed-file, permission,
generated-config, nft and routing checks. VPN reachability, country providers,
FakeIP probes and external service checks no longer gate installation or
version activation. Existing VPN configuration and profiles are not changed.

Network diagnostics remain truthful: installation may succeed with network
STATUS=UNKNOWN or FAIL; that value remains visible in Monitoring and updater
state. Missing/stale Monitoring cycles and failed local services still stop
installation. The explicit diagnostic verifier modes health/all remain strict;
the installer uses the separate installation mode.

Components: bundle 1.7.11, Monitoring 1.7.9, existing Go agent 1.7.10 and Failover
1.5.0. Monitoring and updater source:
43d1f2a1fdac659788dbb358728ab16e2de411b8. The unchanged Go package remains pinned
to the already-published 1.7.10 archive, source 0c8fd86, with its original hash.
Python/age packages are not installed or automatically removed.

Rollout remains manual. Published 1.7.10 assets are unchanged. The initial update
from an older updater with strict VPN gating must use the 1.7.11 bundle installer
directly; after this update, the installed updater uses the corrected gate.
