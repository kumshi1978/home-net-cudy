# HOME NET 1.7.10 — Go router agent

Router-side control now uses one statically linked Linux ARM64 Go executable.
The normal bundle installer no longer requires Python, Python SSL, age or
age-keygen for 1.7.10. age X25519 encryption, HTTPS, signed jobs and the existing
panel protocol remain in use. Device identity and credentials are preserved.

The same executable provides slot preparation, persistence and rebinding.
The reviewed shell controller and adapter use the native persistence and
decryption commands. Python sources remain regression oracles and support
historical bundles; they are not installed by the native package.

The bundle verifies the native bootstrap and archive hashes, runs native
preflight before changing runtime components, and reuses the maintenance lock.
The agent installer retains the old program inodes as private hard-linked
backups before atomic replacement. Failure before activation retains the old
code; activation failure restores replaced code. Unreviewed custom files and
unfinished VPN transactions stop installation. No automatic package removal.

Components: HOME NET 1.7.10; Go agent 1.7.10; Monitoring/LuCI 1.7.8;
Failover 1.5.0. Monitoring, Failover and updater sources remain pinned to the
previous reviewed immutable commits. The native source is
0c8fd86cbd9897c665cc497ba1e59c6d4e0cf581; bootstrap source is
4937f5cb273a088a35d6d88c2dee96a5f0a7cadd. The native archive SHA256 is
dfa076c50391bd54d927bb7124dd34cc23410593ccb96fb1f75dca2d14c72cb3.

Supported native architecture: aarch64 (including the two Cudy TR3000 devices).
Other architectures fail before changing components. Existing Python and age
packages are retained because other software or rollback may require them.
No firmware update, automatic rollout or automatic role assignment is included.

The release policy points to v1.7.10 in manual mode; publication does not trigger
router installation. Hardware order: test the main Cudy first; test the backup only after the
operator confirms WAN has been switched to the main router.
