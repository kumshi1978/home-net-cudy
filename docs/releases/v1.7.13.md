# HOME NET 1.7.13 — сохранение проверенного VPN-профиля

Исправлена остановка доставки со статусом «Требуется восстановление» после успешной проверки резервного VPN. Модуль сохранения вызывал неподдерживаемую команду `awg show all listen-ports`. Теперь используется поддерживаемый параметр `listen-port`; проверка уникальности локальных портов сохранена.

Добавлены регрессионные проверки полного сохранения профиля с ListenPort и отказа без изменений при конфликте локальных портов.

На резервном Cudy установлена проверочная сборка исправления, сохранён уже проверенный резерв через панель. Операция закрылась, профиль записан в постоянную конфигурацию: один актуальный peer, Endpoint port и Listen port сохранены, Default gateway отключён, пользовательские DNS отсутствуют. Основное подключение осталось активным. Подробности и границы проверки — в HARDWARE_VALIDATION.md.

## Как обновить основной Cudy

В HOME NET откройте обновления, проверьте наличие версии 1.7.13 и запустите ручное обновление. Дождитесь завершения и нового отчёта агента в панели. Обновление выполняет владелец; автоматический rollout не включён.

Если прежняя доставка завершилась ошибкой и резерв ещё не проверен, после обновления откройте в панели «Роутеры → Основной и резервы» и повторите доставку только для неактивного резерва. Если показана кнопка «Сохранить проверенный резерв», используйте её для завершения существующей операции. Не создавайте вручную второй peer или новый интерфейс поверх существующего.

Резервный профиль до успешного сохранения не следует считать готовым к перезагрузке. Обновление не восстанавливает автоматически задачи, уже завершённые ошибкой.

Monitoring 1.7.9, Failover 1.5.0, ключи шифрования и действующие назначения сохраняются. Перенос имени панели в конфигурацию роутеров остаётся отложенным.
