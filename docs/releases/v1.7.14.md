# HOME NET 1.7.14 — защита перепривязки VPN (release candidate)

## Исправлено
- Native agent не выполняет повторно уже применённый подписанный `rebind` той же ревизии и контрольной суммы.
- При повторном запросе сначала проверяется реальное состояние VPN-слотов (адреса, порты, интерфейсы и отпечатки). Если состояние изменилось, агент сообщает об ошибке привязки и требует явного вмешательства вместо опасного повторного изменения сети.
- Сохранение `apply_failed_revision` остаётся независимым от успешного `rebind`; это отдельное подтверждение полного порядка плана.
- Панель: исправления слиты в `home-net-vpn-control` branch `feature/device-client-management`, commit `ba58d4c8`. Ошибочный порт AESA Main DE был исправлен непосредственно в базе FirstVDS на 3333; повторные rebind прекратились.

## Проверено
- PR #41: Native router agent и HOME NET CI прошли полностью.
- Cudy apartment-main: после исправления порта `awg_main=194.62.66.234:3333` и `awg_backup=89.23.108.202:4343`, применена ревизия 4, `apply_failed_revision` отсутствует, счётчик rebind зафиксирован на 90, основной VPN работает.
