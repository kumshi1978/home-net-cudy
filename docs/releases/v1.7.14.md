# HOME NET 1.7.14 — защита перепривязки VPN (release candidate)

## Исправлено
- Native agent не выполняет повторно уже применённый подписанный `rebind` той же ревизии и контрольной суммы.
- При повторном запросе сначала проверяется реальное состояние VPN-слотов (адреса, порты, интерфейсы и отпечатки). Если состояние изменилось, агент сообщает об ошибке привязки и требует явного вмешательства вместо опасного повторного изменения сети.
- Сохранение `apply_failed_revision` остаётся независимым от успешного `rebind`; это отдельное подтверждение полного порядка плана.
- Панель: исправления слиты в `home-net-vpn-control` branch `feature/device-client-management`, commit `ba58d4c8`. Ошибочный порт AESA Main DE был исправлен непосредственно в базе FirstVDS на 3333; повторные rebind прекратились.

## Проверено
- PR #41: Native router agent и HOME NET CI прошли полностью.
- Cudy apartment-main: после исправления порта `awg_main=194.62.66.234:3333` и `awg_backup=89.23.108.202:4343`, применена ревизия 4, `apply_failed_revision` отсутствует, счётчик rebind зафиксирован на 90, основной VPN работает.
- Эти проверки НЕ являются аппаратной проверкой новой сборки 1.7.14.

## Блокеры публикации стабильного релиза
1. Сборка `home-net-native-agent-1.7.14-linux-arm64.tar.gz` и фиксация точного source commit, `SHA256SUMS`, `release-lock.json`; CI и проверка архива.
2. `control-agent/install-native.sh` пока **указывает на v1.7.13**. До публикации требуется закрепить SHA-256 нового 1.7.14 архива и точную ссылку на immutable release. Нельзя считать текущий candidate готовым к установке.
3. Сравнить deployed `/opt/vpn-control/server.py` с объединённым исходником панели, чтобы не затереть локальные правки.
4. Провести canary аппаратный тест на резервном Cudy; основной квартирный роутер обновлять вручную после проверки.
5. Публикация GitHub Release с тегом `v1.7.14` и архивами требует отдельного действия. До этого обновление через updater не должно предлагаться.

## Rollout
`DEFAULT_AUTO_UPDATE_MODE='check'`; автоматическая установка не включается. Не менять VPN-профили и ключи при установке. Сохранять rollback и проверять фактический `applied_revision`.
